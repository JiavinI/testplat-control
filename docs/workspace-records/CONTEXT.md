# testplat 领域术语

面向测试人员的接口自动化测试平台。以下术语区分业务测试资产、被测系统配置和使用平台的人。

## Language

**资产仓库**：保存一个或多个业务项目的接口定义、测试场景和登录流程的版本化仓库。
_Avoid_：把资产仓库、业务项目、被测系统当作同一个概念。

**业务项目**：用于区分订单等业务数据归属的项目，如 GO2、E3E3。同名网站本身也是被测平台，业务归属与被测平台两个含义需按上下文区分。
_Avoid_：把 GSB、代发后台等平台当作业务项目，或把业务项目等同于资产目录。

**被测平台**：测试中访问的网站或业务平台，包括 GO2 网站、E3E3 网站、各自的 GSB，以及代发后台、拿货端、GO2 管理后台。GO2 和 E3E3 各自拥有自己的 GSB，不能只作为一个公共 GSB 下的项目选项。
_Avoid_：TestPlat 自身、平台用户、把网站平台仅当作项目标签。

**所属网站的 GSB**：GO2 的 GSB、E3E3 的 GSB 等属于各自网站的平台，沿用所属网站的登录身份。通用功能相似不改变其网站归属。
_Avoid_：用一个公共 GSB 下的项目标签替代各网站及其 GSB。

**被测系统**：测试中访问的系统的统称，包括业务网站及服务这些网站的被测平台。
_Avoid_：默认所有被测系统都使用同一套登录身份。

**网站登录身份**：用于登录 GO2、E3E3 等网站平台的用户身份。各网站自己的 GSB 沿用所属网站的身份进入；不同网站的身份需要区分。
_Avoid_：把身份相同等同于所有协议都使用相同 Cookie 或 token。

**后台登录身份**：用于登录代发后台、拿货端、GO2 管理后台等独立入口的身份。处理哪个业务项目的订单，与使用哪个后台账号分别确定。
_Avoid_：把切换业务项目等同于切换网站登录身份。

**项目环境**：所选被测平台与业务项目适用的一套运行配置，如 test 或 pre。网站与自身 GSB 可共用身份及环境，独立后台使用各自配置。
_Avoid_：所有平台共用全局账号，或把后台处理订单的项目当作登录账号归属。

**测试账号**：用于登录被测系统的业务身份。网站账号按业务项目区分，独立后台账号按所属被测平台区分；环境和账号名共同确定具体身份。
_Avoid_：TestPlat 平台用户、把后台账号与网站账号混用。

**账号名**：测试场景引用的测试账号标识，与可变更的登录用户名分开。
_Avoid_：把登录用户名、密码或业务角色描述当成唯一定位条件。

**登录账号**：实际登录被测系统的用户名，例如手机号或中文用户名。与场景使用的账号引用分别展示；不包含密码、Cookie 或令牌。
_Avoid_：用引用名或展示名冒充实际登录用户名。

**资产默认值**：接口或场景自身的常用业务输入，归对应接口或场景维护。
_Avoid_：把所有接口和场景的业务输入集中放进环境配置。

**环境参数覆盖**：同一输入在 test、pre 等环境中的差异值，覆盖资产默认值。共享环境配置中的同名输入会影响使用它的多个资产。
_Avoid_：把环境覆盖当作某个接口专属的默认值。

**单次运行参数**：本次调试或执行显式填写的输入，优先于环境覆盖和资产默认值，不自动保存成默认值。
_Avoid_：把一次调试修改自动变成所有后续运行的配置。

**公共配置**：跨接口或场景统一维护的运行策略或基础服务配置，如日志、脱敏、默认超时和服务连接。每个值应有明确作用范围和来源。
_Avoid_：将商品关键词、订单号等业务输入当作全局配置。

**业务角色**：被测系统中的职责，如商家、调度员；同一角色可以有多个测试账号。
_Avoid_：平台权限角色。

**平台用户**：注册并登录测试平台、维护配置和发起执行的人。
_Avoid_：测试账号、被测系统账号。

**操作人**：一次平台操作的发起用户，与该次测试使用哪个测试账号分别记录。
_Avoid_：用测试账号充当操作人。

**登录流程**：描述如何登录被测系统、取得登录态并用于业务请求的定义。
_Avoid_：把流程与某一份账号密码绑定成一个不可替换的整体。

**接口定义（API）**：可重复使用的单个接口契约，描述业务输入与实际请求、成功条件之间的关系。
_Avoid_：把整条业务场景塞进一个接口定义。

**测试场景（case）**：围绕一个业务目标按顺序组织接口调用、账号选择、数据传递和结果检查的测试单元。
_Avoid_：只按接口数量判断场景边界。

**公共流程（flow）**：被多个测试场景复用的一组业务步骤，有明确输入与产出。
_Avoid_：要求每个简单场景先抽一层公共流程。
