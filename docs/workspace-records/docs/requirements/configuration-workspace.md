# 配置入口、环境与参数归属

日期：2026-10-18。用户已同意本设计；按小步实施，本文区分目标与已实现行为。平台及项目关系继续以 [平台与项目](platforms-and-projects.md) 为准。

## 用户目标

账号列表直接展示实际登录账号，同时保留分组、引用名及完整引用；密码不进入列表。不引入另一个需人工同步的展示名。登录账号从已保存的凭据中取 username，不能用旧 display_name 替代。

环境维护先选择环境，再直接展示该环境的完整 Host。按 API、登录、网站等用途分组，编辑时完整地址可换行。网站与自身 GSB 共用的环境仍保存一份，页面明确影响范围；不能因当前只测一个平台而在保存时丢弃同份配置中的其它服务。未知服务名保留并可维护。

## 参数目标与覆盖规则

| 内容 | 管理位置 | 作用范围 |
| --- | --- | --- |
| 接口默认值 | 接口管理中的当前接口 | 当前接口 |
| 场景默认值 | 场景测试中的当前场景 | 当前场景 |
| 环境覆盖 | 对应接口／场景的环境参数入口 | 指定资产与环境 |
| 单次输入 | 接口／场景运行页 | 本次执行 |
| 多处复用的业务参数 | 后续公共参数管理及使用页引用 | 明确的共享范围 |

优先级：资产默认值 < 环境覆盖 < 单次显式输入。按顶层键覆盖，值为对象时整体替换；不能偷偷增加跨接口、跨场景同名参数继承。后续使用页需要显示有效值、来源与影响范围，环境和参数较多时支持查找。临时调试不自动保存为默认值。

当前代码已经支持接口 inputs.default、场景资产 params 和运行时环境 case_params／临时输入合成，不能重复实现。现有 case_params 属于共享环境覆盖：暂时继续生效、保留编辑入口，并明确其兼容身份。目标中的“按资产＋环境”覆盖尚未实现，迁移必须单独设计映射、冲突检查和回退，不自动搬动或清空现有值。完整请求体覆盖仍按现有整体替换规则执行，不改变为参数深合并。

## 配置菜单目标

配置主要维护公共、低频的策略及连接：日志级别、请求响应记录、脱敏开关和规则、默认超时、历史保留、并发策略、数据库／Redis 等服务连接。业务参数在使用页面维护；平台、环境、Host、账号可从运行上下文快速进入维护，迁移期间保留现有配置路由。

公共值按实际需要确定全局、平台、业务项目、环境等适用范围，不把这些层级全部强制串成一条继承链；接口和场景是各自资产范围。页面应说明当前值来源、覆盖规则和修改影响。连接凭据安全存储，不把数据库密码、Cookie、主密钥放进普通参数；主密钥仍由部署管理。

## 第二切片：运行页参数来源（已完成）

接口参数区展示资产默认值、兼容环境覆盖、单次输入及最终采用的值；输入框只填写本次覆盖，不将默认值复制进提交体。清除本次输入可恢复默认值，布尔 false、数字 0、资产中的空字符串均按实际后端规则处理。无效环境值仍覆盖资产值，页面提示类型问题，不擅自回退后宣称可运行。

场景参数从现有资产树提供的顶层 params 展示，仍由 Engine 负责完整语义与运行预检；Control 不增加第二套场景解析器。场景支持单次 JSON 参数覆盖和来源预览，对象按顶层整体覆盖，支持 null／false／0。不会编辑步骤或写回 Assets。切换环境、项目、资产清除本次草稿；完整请求体模式明确绕过模板参数预览。

本切片不写入持久化默认值。验收以页面来源与实际提交一致、不同环境不沿用旧输入、假服务／隔离库请求的合成结果一致为准。

预览展示模板输入参数，不承诺最终请求体的字段类型。当前 Engine 的单接口模板插值会把 number／boolean 转成字符串，场景步骤引用解析则保留类型；本轮不改变这项既有差异，最终以执行后的请求展示为准。完整请求体覆盖仍原样发送。

按资产＋环境持久化详见 [存储方案](../../notes/asset-parameter-storage-design-2026-10-18.md)，已接续实施，见下一切片。

验证记录：Control 全量 402、前端全量 187、前端 lint/build 通过；隔离假目标验证真实 Engine 的参数合成及渲染请求，浏览器假数据验收桌面／390px，页面错误 0。未扩大为真实搜索或完整场景验收。

## 第三切片：按资产与环境保存参数

用户已同意实施。接口／场景使用页面增加“维护默认值”“维护当前环境覆盖”，先用 JSON 对象维护差异值。两类值均属于实际平台、项目、资产；默认值适用于各环境，环境覆盖只影响指定环境。Git 默认值作为只读基线，共享 case_params 继续生效。

保存整份替换本层，移除键／清空对象恢复下层；null 是值（接口仍需符合声明类型，场景允许 null）。初始 revision=0，之后必须提交读取版本及 commit。冲突提示刷新，保留草稿、不自动覆盖。保存后的上下文更新来源预览，单次输入仍只在显式保存入口外临时使用。

验收包括：保存／刷新／运行闭环、不同工作区与环境隔离、顶层整体替换、409 冲突、执行冻结及历史不随后续修改变化、原库加表兼容。测试只用隔离库与假服务。现有预览后端本轮未重启或加表；其保存功能未启用时保留既有调试入口。共享值迁移、孤立参数集管理、公共配置开关仍未实施。
