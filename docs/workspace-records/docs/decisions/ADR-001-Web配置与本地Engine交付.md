# ADR-001：Web 配置与本地 Engine 交付

状态：已采用
日期：2026-10-16

## 决定

正常 Web 运行默认只使用数据库中的项目环境和测试账号；Git 保留接口定义与登录流程。仅显式设置 `TESTPLAT_LEGACY_GIT_CONFIG=true` 时，完全没有数据库环境的旧项目才可使用历史 Git 环境 / auth。已有数据库环境的项目不允许因环境、host 或账号缺失而回退。

在远程 Engine 扩展尚未获准推送前，保留可获取的旧远程锁定，并提供校验依赖来源的本地开发入口。旧包缺少请求覆盖契约时启动失败；开发入口显式安装相邻 Engine 的已提交源码，不依靠现有虚拟环境。三仓本地提交加干净克隆验证作为本轮交付。

## 原因与影响

自动回退会让未配置的 Web 项目意外读取 Git 或服务器业务凭据；删除旧路径又会丢失仍有价值的兼容证据，因此默认关闭、显式启用，并对正常与兼容模式分别测试。测试开关通过 pytest 标记启用，不改变生产默认值。

将未推送的 Engine SHA 写进远程来源会使新安装失败；远程操作目前未获授权。后续先交付 Engine，再用可获取的精确 SHA 更新 Control 的来源与锁文件，重新验证不含本地覆盖的全新安装。本轮本地复现通过不等于远程发布完成。
