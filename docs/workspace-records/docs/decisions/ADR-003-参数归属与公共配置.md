# ADR-003：参数归属与公共配置

状态：已采用（分步实施）
日期：2026-10-18

## 决定与背景

业务默认值归接口或场景自身，环境仅保存差异覆盖，单次执行显式输入最高优先。按顶层键覆盖，接口和场景分别管理，不建立“接口继承到场景”的隐式链。配置菜单逐步收敛为公共运行策略、基础服务连接及平台环境管理，使用页面能查看生效值与来源。集中存放全部业务输入会使同名字段跨资产耦合，随接口、场景和环境增加难以判断修改影响。

## 兼容影响

现有资产默认值及 Web 环境 case_params 已有覆盖链路，不能重做或宣称尚无此能力。当前共享 case_params 保留，未来按资产＋环境迁移须有显式映射、冲突检查和回退；在新模型落地前不能只移动界面标签就声称已隔离。公共配置各自选择实际需要的作用域，不能从全局到场景机械套用一条深继承链。普通 Web 运行继续只从数据库取得环境和账号。

目前已实现账号可读性、环境展示、运行页参数来源预览及按资产／环境保存参数；保存与运行在隔离库验收，现有预览库未加表。共享值迁移尚未实施。完整目标及验收见 [配置工作区需求](../requirements/configuration-workspace.md)。
