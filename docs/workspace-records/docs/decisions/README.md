# 架构决策记录

这里记录会影响多个文件、多个仓库或后续阶段的重要决定。

命名：`ADR-NNN-简短主题.md`。

每条记录至少包含：

```markdown
# ADR-NNN：标题

状态：提议 / 已采用 / 已废弃
日期：YYYY-MM-DD

## 决定

一句话说明最终采用什么。

## 背景

为什么需要做这个选择。

## 原因

列出对用户、兼容性、测试和维护的影响。

## 未采用方案

记录关键替代方案以及不采用的原因。

## 影响

说明代码、文档、测试和后续任务需要遵循什么。
```

不要为局部变量或一次性排版选择创建 ADR。若新决定取代旧决定，应更新旧记录状态，并在新记录中链接旧记录。
