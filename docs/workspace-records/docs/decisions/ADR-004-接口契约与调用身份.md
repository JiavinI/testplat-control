# ADR-004：接口契约与调用身份

状态：已采用
日期：2026-10-19

## 决定

GSB API 只定义业务请求契约，不固定测试账号。调试请求通过 identity 选择身份，场景 API 步骤通过 identity 选择身份；显式 none 表示匿名。旧资产 auth 字段仅作为未提供调用身份时的兼容回退，不再作为接口管理的固有鉴权属性展示。

## 背景与原因

同一个运费或订单查询接口可被 GO2/E3E3 的多个测试账号调用。把账号放进 API 会把通用契约与一份运行配置绑定，无法复用；项目限制表达的是接口适用业务范围，与使用哪个账号分别处理。原渲染模式有既有兼容承诺，因此新增显式结构化模式，避免改变旧契约的字符串插值行为。

## 未采用方案

不复制公共接口到两个项目目录，也不只隐藏鉴权标签而保留固定身份。直接剥除 ! 会丢失必填约束；将嵌套对象全部拆成平铺字段会改变原调用接口，因而保留源模板并补足受限渲染能力。

## 影响

公共接口保留一份。项目专属接口保留 go2/e3e3 目录并声明 projects，由运行环境的 business_project 校验；Control 使用已有平台项目绑定提供该字段，不根据账号名推断项目。项目登录流程取得对应 token/用户 Header；CSRF 流程独立声明 X-SOURCE，不将猜测的 Header 写入公共 API。

迁入接口显式使用 request.template: structured。该模式保留完整占位符 JSON 类型，支持 ! 必填、默认值、点分对象路径和源目录实际使用的 now()/date_add_days()；缺失可选字段省略，必填缺失在发送/登录前拒绝。原未标记资产保持既有渲染行为。输入对象/数组通过 JSON 表单编辑，必填叶路径由引擎最终校验。

## 兼容与验证边界

旧余额与搜索 ID 保留兼容入口，移除账号绑定；已有场景在调用步骤声明原身份。checks 不属于当前 Case DSL，保存为参考，不进入 API 可运行目录。不执行真实资金与订单写入；验证使用隔离数据库和假 HTTP 服务。本地 Engine 源码与远程锁定依赖的差异需明确记录，不自动变更远程版本。
