# 按资产、环境维护参数：兼容存储方案

状态：用户已同意，保存／读取／运行冻结已实现并在隔离库验收；共享参数迁移未实施，现有预览库未加表。承接 ADR-003。

## 归属与键

建议新增独立参数集表，不复用环境 JSON：`project_id + asset_type + asset_id + scope + env_key` 唯一。scope 仅 asset_default／environment_override；asset_default 的 env_key 固定空串，环境覆盖使用实际环境名，避免数据库 NULL 唯一键语义差异。每行保存 JSON values、revision、updated_by、updated_at；删除覆盖通过带 revision 的清空 values 保留版本，防止删除重建引起旧客户端覆盖。

本切片已按该结构新增 `parameter_sets` 表；既有 create_all 仅加表，不 ALTER／DROP 或改旧行。初次保存必须 revision=0，之后使用 CAS 更新并递增 revision；空对象仍保存行。审计只记录 values 字段名，不记录值。普通参数集拒绝密码／令牌等敏感键及嵌套键，凭据仍使用测试账号入口。

project_id 使用实际运行工作区，不跟随环境 owner 自动共享。GO2 网站与其 GSB 可以共享 Host 和身份，但同名业务参数不应因此互相影响；未来显式公共参数引用另行建模。参数属于稳定资产 ID，Git commit 是预览和执行时绑定的版本，不放入唯一键。同步资产删除或更名时保留原配置并标记孤立待处理，不自动搬至同名资产。

## 合成与兼容

后续采用：Git 资产默认值 < 数据库资产默认值 < 兼容共享环境值 < 当前资产环境覆盖 < 单次输入。数据库资产默认值让使用页保存常用输入，Git 值继续提供基线；不写回 Assets。接口只取声明字段，场景允许合法 JSON 顶层输入；值为对象时整体替换。null 是值，不代表删除覆盖；删除通过显式操作移除对应键。不同层同名键按优先级选择，不深度合并。

兼容共享 case_params 暂不自动复制：接口只接收声明过的键，场景还可引用嵌套路径及运行时额外参数，不能仅按同名匹配猜测归属。迁移先生成“共享键 → 受影响资产＋环境＋工作区”映射和冲突清单，由使用页明确选择复制目标。目标采用显式每键替换或保留规则，迁移中原共享值仍生效；只有确认所有消费者已迁移后才单独移除共享键，删除前后对比有效参数。

## API、运行和回退

读取接口返回当前资产、环境、commit、参数集 revision、环境 revision 和每键有效值及来源；保存需要 revision 与读取时的 commit，防止资产变更后向旧字段保存。所有入口需登录、校验资产存在、环境所属及 JSON 参数；凭据不进入普通参数集。

已实现 GET `/repos/{repo}/projects/{project}/parameter-sets/{api|case}/{asset_id}?env=...` 与 PUT 同路径再加 `/{asset_default|environment_override}`；环境覆盖 PUT 必须 env，资产默认值不接受 env。接口保存仅接受当前声明的名称和类型；场景仅保存普通 JSON 对象，顶层 params 投影复用现有资产树，完整语义仍由 Engine 预检。不存在的资产不可读写，不自动搬迁残留行；孤立参数清单管理尚未实现。

运行在既有冻结事务内读齐参数集／环境版本并形成最终参数与来源快照，再结束事务调用 Engine。历史只读当时快照。共享参数变更与资产默认值变更分别记版本；并发冲突 409，不用自动重试覆盖。

SQLite 路由读取在资产／环境查询前显式 BEGIN，保存使用 BEGIN IMMEDIATE 串行化 SHA 校验和 CAS。snapshot.parameters 保存 effective（敏感键脱敏）、sources 和 revisions；历史不回查现值。场景资产默认值仍由 Engine 合成，Control 传入数据库／环境／临时的覆盖层，未重写 Case 解析。单接口完整 body 覆盖仍原样发送、不渲染。

上线先在临时文件库验证新增表与重复迁移无变化，原环境／账号密文／历史／主密钥保持不变。预览应用只做加表，不清库；移除新表功能时保留行，旧执行模式可继续读取共享值。迁移删除共享值后需显式审查恢复清单再回退，不让停用新功能静默丢失默认值。真实数据变更在独立切片完成，不由本次来源展示触发。

已用隔离文件库验证两次初始化只新增表、所有旧表行完全相等及重连后参数可读。依用户保护现有预览库的约束，本轮未重启原后端加表；旧服务明确缺路由（404 Not Found）时页面保留旧调试并提示保存未启用，已存在路由的资产／环境错误不触发兼容回退。部署前仍需先备份并审查加表动作。
